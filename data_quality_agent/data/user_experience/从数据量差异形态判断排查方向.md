# 方法论：先从数据量差异形态判断排查方向

拿到校验平台的“源表与目标表数据量不一致”告警后，不要急着打开作业看细节。
先用“差异形态”确定方向，再进 Flink UI 验证，能省下大量时间。

## 四种常见差异形态

### 1. 突然缺口：某一天/某个时段少一块
- 特征：其他日期一致，只有某个日期对不上。
- 优先假设：分区缺失、作业失败/重启、上游断流。
- Flink UI 验证：作业状态（FAILED/RESTARTING）、Sink 端 records-sent 走势、
  Checkpoint 状态、失败日志。

### 2. 稳定偏差：每天差异量级差不多
- 特征：每天告警，差异比例基本恒定，随天数线性累积。
- 优先假设：去重口径不一致、过滤口径不一致、维表 JOIN 行数放大/缩小。
- Flink UI 验证：审阅作业 SQL（DISTINCT/GROUP BY/JOIN/WHERE），
  对比拓扑中 JOIN 前后算子行数。

### 3. 随时间累积：差距越来越大
- 特征：目标表永远落后源表一段，且落后量持续增长。
- 优先假设：同步延迟、背压/资源不足、水位线停滞、Checkpoint 反复失败。
- Flink UI 验证：Watermark / currentFetchEventTimeLag、Kafka 消费 lag、
  背压状态、Checkpoint 状态。

### 4. 固定比例：目标表恒为源表的某个比例
- 特征：目标表稳定是源表的 80%~90% 之类的固定比例。
- 优先假设：抽样/限量逻辑、源表重复数据 + 目标表去重。
- Flink UI 验证：作业 SQL 中 LIMIT / 抽样 / 去重逻辑。

## 快速定位路径
1. 先看校验平台多天走势，判断属于哪种形态。
2. 再看 Flink UI 作业状态与 Checkpoint（排除作业层故障）。
3. 再看 Source/Sink 指标与水位线（判断数据有没有在流动）。
4. 最后审阅作业 SQL（确认口径类问题）。

## 注意
- 一次告警只有一个窗口的数据量时，形态信息有限，优先查作业状态与 Sink 指标。
- 形态判断只能缩小范围，最终结论必须有 Flink UI 的具体观察支撑。
